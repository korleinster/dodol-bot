## 기술 스택

| 항목 | 내용 |
|---|---|
| 언어 | Python 3.11 |
| 봇 프레임워크 | discord.py 2.3 |
| TTS | edge-tts (Microsoft, `ko-KR-SunHiNeural`) |
| 데이터베이스 | SQLite + aiosqlite |
| 시세 API | PLAYNC 개발자센터 (`dev-api.plaync.com/l2m/v1.0`) |
| 배포 | Railway (Volume 영구 저장소 + nixpacks FFmpeg) |

## 설치 및 실행

```bash
# 의존성 설치
pip install -r requirements.txt

# .env 파일 생성
cp .env.example .env
# .env 편집 후 토큰/API 키 입력

# 실행
python main.py
```

> **FFmpeg 필요** — TTS 음성 재생에 사용됩니다.  
> macOS: `brew install ffmpeg` / Ubuntu: `apt install ffmpeg`

## 환경변수 설정

`.env.example` 을 복사해 `.env` 로 저장 후 아래 값을 입력합니다.

```env
# 봇 토큰 (번호별 — 없는 번호는 인스턴스 미생성)
DISCORD_TOKEN_001=your_token_here
#DISCORD_TOKEN_002=your_token_here
#DISCORD_TOKEN_003=your_token_here

# PLAYNC 개발자센터 API 키
PLAYNC_API_KEY=your_api_key_here

# DB 경로 (Railway Volume 마운트 경로로 변경)
DB_PATH=./data/bot.db
```

봇 토큰은 [Discord Developer Portal](https://discord.com/developers/applications) 에서 발급합니다.  
PLAYNC API 키는 [PLAYNC 개발자센터](https://developers.plaync.com) 에서 발급합니다.

## 봇 배치 (소환)

봇을 처음 서버에 추가하면 모든 채널에서 `.소환 001` 명령으로 배치합니다.

```
.소환            ← 서버 내 모든 도돌봇 배치 현황 확인
.소환 001        ← 도돌봇001을 현재 텍스트 + 음성 채널로 배치
.설정            ← 현재 이 봇의 배치 채널 확인
```

- 음성 채널은 명령 입력 시 사용자가 **입장해 있는 음성방**으로 자동 설정됩니다.
- 배치 후에는 설정된 텍스트 채널에서만 명령이 동작합니다.

## 명령어 목록

모든 명령어는 `.` (마침표) 로 시작합니다.

### 채널 설정

| 명령어 | 설명 |
|---|---|
| `.소환` | 서버 내 모든 도돌봇 배치 현황 |

| `.설정` | 현재 봇의 채널 설정 확인 |

### 보스 관리

#### 보스 목록 확인
```
.보스
```

#### 보스 등록
```
.보스등록                                    ← 도움말 출력

.보스등록 3:00:00 체르투바                   ← 3시간 리스폰
.보스등록 3:00:00 체르투바(ㅊㄹ)             ← 별명 포함 (초성 검색용)
.보스등록 3:00:00 체르투바(ㅊㄹ,체르) 서버기동  ← 서버 재시작 시 스폰
.보스등록 3:00:00 체르투바 딜레이 1:00:00   ← 서버오픈 후 1시간 딜레이

.보스등록 20:00:00 필드이벤트 고정           ← 매일 20시 고정 알림
.보스등록 23:00:00 주말이벤트 고정 (토일)   ← 토/일 23시 고정 알림
```

#### 보스 삭제
```
.보스삭제 체르투바
```

### 컷 / 멍

**컷** — 보스를 처치했을 때 입력. 처치 시각 기준으로 다음 리스폰 자동 예약.

```
.체르 컷               ← 지금 잡은 경우
.컷 체르
.체르투바 컷
.컷 체르투바

.체르 컷 0530          ← 05:30 에 잡은 경우 (HHMM 또는 HH:MM)
.체르투바 컷 0530
.컷 체르 0530
.05:30 체르 컷

.ㅊㄹ ㅋ               ← 초성 검색 + ㅋ(컷 단축키)
.ㅋ ㅊㄹ
.ㅊㄹㅂㅌ ㅋ
.컷 ㅊㄹ
```

**멍** — 보스가 스폰됐지만 처치하지 못한 경우. 직전 예약 시각 기준으로 다음 리스폰 계산.

```
.체르 멍
.멍 체르
```

### 예약 관리

```
.보탐               ← 예약 목록 (고정 제외)
.보탐+              ← 예약 목록 (고정 포함)
.bt                ← 남은 시간 기준 예약 목록
.bt+               ← 남은 시간 기준 (고정 포함)

.보탐 초기화        ← 고정 제외 모든 예약 삭제

.z / .ㅋ            ← 다음 예약 1개 확인
.Z                  ← 다음 예약 1개 확인 + TTS 음성 알림

.22:30 체르투바     ← 22:30 에 체르투바 알림 예약 (임의 내용도 가능)
.22:30 밥 먹자      ← 22:30 에 '밥 먹자' 알림

.체르 삭제          ← '체르' 포함 예약 전체 삭제
.22:30 이프 삭제    ← 특정 시각 + 내용으로 1건만 삭제
```

---

### 오픈타임 / 서버오픈

**오픈타임** — 서버 오픈 기준 각 보스의 첫 리스폰 딜레이 설정.

```
.오픈타임                       ← 보스별 오픈타임 확인
.오픈타임 10:00:00 체르투바     ← 체르투바 오픈타임을 10시간으로 설정
```

**서버오픈** — 점검 후 서버 기동 시각 입력. 등록된 보스 전체를 오픈타임 기준으로 미입력 예약.

```
.05:00 서버오픈     ← 05:00 오픈 기준으로 전체 보스 예약
```

- 현재 시각 ±8시간 범위의 시각만 입력 가능.
- 이미 예약된 보스는 스킵.

---

### 자동예약

컷/멍 미입력 시 자동으로 예약 처리되는 유예 시간 설정 (기본 10분).

```
.자동예약                           ← 보스별 자동예약 시간 확인
.자동예약 0:30:00 체르투바          ← 체르투바 자동예약 유예시간 30분으로 변경
```

---

### TTS

배치된 음성 채널에서 텍스트를 읽어줍니다. 음성: `ko-KR-SunHiNeural`.

```
.v 좋은 아침입니다          ← 해당 텍스트를 음성 채널에서 읽어줌
.정신차려                   ← 음성 장애 시 재접속
```

---

### 시세 검색

PLAYNC 개발자센터 API를 통해 거래소 시세를 조회합니다.

```
.시세 집행검                ← 아이템 검색 + 가격 통계 + 서버별 최저가
.시세 +15 집행검            ← 강화 수치 포함 검색 (추후 지원)
.서버목록                   ← 서버 ID/이름 목록 확인
```

### 미니게임

```
.주사위                     ← 1~6 주사위
.주사위 100                 ← 1~100 주사위
.동전                       ← 앞면/뒷면

.숫자게임시작               ← 1~100 숫자 맞추기 시작
.숫자맞추기 42              ← 숫자 입력

.뽑기                       ← 참여자 중 1명 추첨
.뽑기3                      ← 참여자 중 3명 추첨
.뽑기 철수 영희 민수        ← 지정 인원 중 추첨

.랭킹                       ← 미니게임 점수 TOP 10
```

## 멀티 인스턴스

하나의 Railway 서비스에서 여러 봇을 동시에 운용할 수 있습니다.

```env
DISCORD_TOKEN_001=token_for_bot_001
DISCORD_TOKEN_002=token_for_bot_002
DISCORD_TOKEN_003=token_for_bot_003
```

- 토큰이 설정된 번호만 자동으로 인스턴스가 생성됩니다.
- 각 봇은 서버별로 독립된 채널/보스/예약 데이터를 가집니다.
- 같은 서버에 여러 봇을 운용하면 채널별로 분리 관리 가능합니다.

## Railway 배포

1. GitHub에 레포지토리 푸시
2. Railway에서 새 프로젝트 생성 → GitHub 레포 연결
3. **Volume 추가**: `/app/data` 경로로 마운트 → `DB_PATH=/app/data/bot.db` 설정
4. 환경변수 설정 (Variables 탭):
   - `DISCORD_TOKEN_001`
   - `PLAYNC_API_KEY`
   - `DB_PATH=/app/data/bot.db`
5. 배포 → Service Type: **Worker** 선택

> `nixpacks.toml` 에 FFmpeg 자동 설치가 설정되어 있습니다.
