# 보스 데이터 명세

`src/db.py`의 `DEFAULT_BOSSES`에 정의. 총 **65개** (일반 61 + 고정 4).

---

## 필드 구성

```
(이름, 리스폰초, spawns_on_open, open_delay초, aliases_json, fixed, fixed_days, fixed_time)
```

| 필드 | 설명 |
|---|---|
| 리스폰초 | 처치 후 다음 등장까지 걸리는 시간(초) |
| spawns_on_open | 서버오픈 연동 여부. 1이면 서버오픈 시 첫 등장 예약 |
| open_delay초 | spawns_on_open=1일 때, 오픈 후 첫 등장까지 지연(초) |
| aliases_json | 초성/별칭 목록 (JSON 배열) |
| fixed | 고정 일정 보스 여부 |
| fixed_days | 요일 (월=0~일=6, 콤마 구분) |
| fixed_time | 시각 (HH:MM, 콤마 구분) |

## 보스 이름 매칭 규칙

`src/korean.py`의 `boss_matches()` 기준.

1. **공백 무관 매칭** — `블랙릴리` ↔ `블랙 릴리`
2. **초성 매칭** — `ㅊㄹㅌㅂ` ↔ `체르투바` (3글자 이상 보스만)
3. **별칭 매칭** — `돌크` → `돌연변이 크루마`, `오크` → `오염된 크루마`
4. **부분 매칭** — 보스 이름이 쿼리를 포함하거나, 쿼리가 보스 이름을 포함하면 매칭
