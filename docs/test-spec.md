# 테스트 명세

`test_bot.py` — 별도 테스터 봇을 통한 E2E 기능 테스트.

---

## 실행 방법

```bash
# .env에 추가 필요
TESTER_TOKEN=테스터봇_토큰
TEST_CHANNEL_ID=테스트할_채널_ID

python test_bot.py
```

- 도돌봇이 이미 배치된 채널에서 실행해야 함.
- 테스터 봇이 명령을 전송하고, 도돌봇의 응답을 수신해 검증.
- 각 테스트 사이 1초 대기.

---

## 테스트 항목 (15개)

| # | 테스트명 | 입력 명령 | 검증 키워드 | 비고 |
|---|---|---|---|---|
| 1 | 도움말 (메뉴) | `메뉴` | `도돌봇` | embed footer 기준 |
| 2 | 보스 목록 | `보스` | `체르투바` | 기본 보스 포함 여부 확인 |
| 3 | 컷 처리 | `체르투바 컷` | `컷 처리`, `다음 리스폰` | embed 필드 확인 |
| 4 | 초성 컷 | `ㅊㄹ ㅋ` | `컷 처리` | 초성 매칭 후 컷 처리 |
| 5 | 멍 처리 | `체르투바 멍` | `멍 처리` | |
| 6 | 초성 멍 | `ㅊㄹ ㅁ` | `멍 처리` | 초성 매칭 후 멍 처리 |
| 7 | 보탐 | `보탐` | `체르투바` | 예약 목록에 포함 여부 |
| 8 | 임의 예약 | `23:59 테스트알림` | `테스트알림`, `예약 완료` | 임의 시각 예약 |
| 9 | 전체 초기화 | `초기화` | `초기화` | 고정 제외 전체 삭제 |
| 10 | 날씨 | `날씨` | `날씨 예보` | Open-Meteo API, timeout 10초 |
| 11 | 시세 검색 | `시세 싸울아비 장검` | `검색` | PLAYNC API, timeout 10초 |
| 12 | 주사위 | `주사위` | `🎲` | |
| 13 | 동전 | `동전` | `앞면` 또는 `뒷면` | 둘 중 하나만 포함되면 PASS |
| 14 | 경마 | `경마` | `경마` | timeout 20초 (애니메이션 대기) |
| 15 | 보스 삭제 불가 | `보스삭제 체르투바` | `기본 보스` | 기본 보스 삭제 시도 → 거부 확인 |

---

## 검증 방식

- 응답 메시지의 `content`, embed `title`, `description`, `field name/value`를 모두 합산한 문자열에서 키워드 검색.
- 응답 없음 (5초 timeout): FAIL — "응답 없음 (timeout)"
- 키워드 미포함: FAIL — `'{keyword}' 없음`

---

## 결과 출력 형식

```
✅ PASS 도움말 (메뉴)
❌ FAIL 시세 검색 — '검색' 없음
⏭️  SKIP (미사용)

==================================================
  결과: 14/15 통과  |  실패: 1
==================================================
```
